# What to Watch

A PHOSPHOR home-screen web app: popular, new and "For you" films and shows across the streaming
services you have (Hulu, Prime Video, Peacock in the US), with browse, search and a ♥ list.
Listings and availability come from the [TMDB](https://www.themoviedb.org/) API (availability data
by JustWatch); paste your own free TMDB API key in Settings. This product uses the TMDB API but is
not endorsed or certified by TMDB.

Live: https://bgriffie.github.io/what-to-watch/

Source lives in `src/`; run `python3 build.py` to rebuild `index.html`.
